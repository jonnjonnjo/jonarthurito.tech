# jonarthurito.tech — Agent guide

## Stack
- **Astro 6** + **MDX** + **Tailwind CSS 4** (Vite plugin, not PostCSS CLI)
- **KaTeX** for math (remark-math + rehype-katex in MDX config)
- All interactive pages are single-file Astro pages with inline `<script>` — no React/Svelte/Vue
- Node >=22.12.0

## Routes (all in `src/pages/`)
| Path | Data source |
|---|---|
| `/` | Static (hardcoded links) |
| `/learning-rigorous` | `src/data/learning-nodes.json` |
| `/learning-books` | `src/data/learning-books.json` + `src/data/goodreads.json` |
| `/learn-hire` | `src/data/hire-projects.json` |

## Commands
```sh
npm run dev          # astro dev — dev server on localhost:4321
npm run build        # astro build — outputs to dist/
npm run preview      # astro preview
npm run sync:books   # pull Goodreads RSS feeds → src/data/goodreads.json
```

## Architecture notes
- Content is entirely **JSON-driven**. Edit the JSON files under `src/data/` to add/modify topics, books, or projects.
- `goodreads.json` is a generated artifact. **Do not edit manually** — run `npm run sync:books` instead.
- Generated types live in `.astro/types.d.ts` (gitignored, regenerated by `astro dev`/`astro build`).
- Tailwind safelist includes `kanagawa-*` color patterns used by the interactive DAG pages.

## Conventions
- Dark/light modes are persisted in `localStorage` with keys `lb-theme` (learning-books) or data-attribute toggle (DAG pages).
- The three DAG pages (`learning-rigorous`, `learn-hire`) share a nearly identical client-side graph renderer. Changes to one likely apply to the others.
- No lint/typecheck scripts configured. Default Astro TS strict mode applies.
- No CI/CD configured.
